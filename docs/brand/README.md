# Vitrina brand files

The mark is an arched shop window, lit, that holds a V. Its construction, colors and rules are in [`apps/dashboard/DESIGN.md`](../../apps/dashboard/DESIGN.md) (Logo). The app draws it from `apps/dashboard/src/components/brand/logo.tsx`; these files are for everywhere else. The suffix names the ground the file is made for.

| File | Use |
| --- | --- |
| `mark-light.svg`, `mark-light-1024.png` | The mark on light grounds |
| `mark-dark.svg`, `mark-dark-1024.png` | The mark on dark grounds: the frame turns light teal |
| `mark-mono.svg` | One ink, in `currentColor`: stamps, embroidery, single-color print |
| `mark-tile.svg`, `mark-tile-1024.png` | Avatars and app icons: the mark on sand |
| `lockup-light.svg`, `lockup-light-2x.png` | Mark and name on light grounds: documents, READMEs |
| `lockup-dark.svg`, `lockup-dark-2x.png` | Mark and name on dark grounds |
| `cover-light-1600x900.png`, `cover-dark-1600x900.png` | Video end cards, slides and posts |

- **Colors:** frame `#0a6170` (`#2ba9be` on dark grounds), glass `#ffae1a`, name `#201c18` (`#faf8f5` on dark grounds); sand `#faf8f5`, night `#062c33`.
- **Clear space:** half the mark's width on every side. **Smallest size:** 16 px for the mark, 24 px tall for the lockup.
- **Type:** the name is Bricolage Grotesque 800, outlined in the SVG files so they need no font (SIL Open Font License).
- Never recolor, outline, rotate or stretch the mark, and never set the name in another typeface.
